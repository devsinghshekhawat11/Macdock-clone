# Milestone 1: Dock MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A transparent, always-on-top dock at the bottom of the primary screen that shows pinned apps with real icons, magnifies smoothly under the cursor, and launches apps with a bounce.

**Architecture:** Three projects per the spec (Core → Interop → App). View models live in Core (CommunityToolkit.Mvvm is platform-neutral), so all dock logic is unit-tested on any OS; Interop holds Win32 calls; App holds WPF views only.

**Tech Stack:** .NET 8, WPF, CommunityToolkit.Mvvm 8.x, Microsoft.Extensions.Hosting 8.x, System.Text.Json, xUnit.

**Spec:** `docs/superpowers/specs/2026-11-24-macdock-design.md` (milestone 1 of 7; milestones 2–7 get their own plans).

## Global Constraints
- Target `net8.0` (Core, tests) and `net8.0-windows` (Interop, App); `Nullable` enabled, warnings as errors.
- Core must not reference WPF, WinForms or any Windows-only API.
- No admin rights required at runtime.
- Idle target: < 1% CPU, < 120 MB RAM; magnification at 60 fps.
- No names, icons or assets copied from the reference product.

## Decisions made in this plan
- Defaults: icon size 48 DIP, spacing 8 DIP, max scale 1.8, magnification range 3 × icon size, cosine falloff.
- Magnification input uses **rest** (unscaled) icon centers, never the current scaled positions, so the layout can't feed back into itself and jitter.
- Dock window is sized once to the fully-magnified bounds and never resized per frame; the visible plate inside it grows.
- Real blur is deferred to milestone 7 (an acrylic window is rectangular and would blur the empty magnification area). M1 uses a translucent rounded plate.
- Config path: `%APPDATA%\MacDock\config.json`.

## Review Focus
1. Cursor leaves the dock or sits exactly on an edge → every icon eases back to scale 1; none stay stuck magnified. (Task 1, Task 2 tests)
2. A pinned app was uninstalled or its path is wrong → generic icon shown, click does nothing harmful, no crash, no bounce. (Task 4 test)
3. Config file missing, empty, or corrupt JSON → defaults are used and the bad file is kept as `config.json.bak`. (Task 3 tests)
4. Display scaling at 125–150% → dock is centered and sits on the bottom edge in DIPs (manual check, Task 6).
5. MacDock started twice → second instance exits immediately. (Task 6 manual check)

**Interfaces — Produces:**
- `record MagnificationOptions(double IconSize = 48, double Spacing = 8, double MaxScale = 1.8, double RangeFactor = 3)` with `double Range => IconSize * RangeFactor`
- `static double[] Magnification.RestCenters(int count, MagnificationOptions o, double containerWidth)` — centers of unscaled icons, row centered in the container
- `static double[] Magnification.ComputeScales(IReadOnlyList<double> restCenters, double? cursorX, MagnificationOptions o)` — `null` cursor → all 1.0

Falloff (the only non-obvious body):
```csharp
double f = d >= o.Range ? 0 : (Math.Cos(Math.PI * d / o.Range) + 1) / 2;
scale = 1 + (o.MaxScale - 1) * f;
```

### Task 6: WPF app — dock window

**Files:** Create `src/MacDock.App/{MacDock.App.csproj, App.xaml, App.xaml.cs, Views/DockWindow.xaml(.cs), Converters/TargetToIconConverter.cs, app.manifest}`

**Interfaces — Consumes:** `DockViewModel`, `IIconProvider`, `ShellAppLauncher`, `JsonConfigStore`

- App startup: named mutex `Local\MacDock.SingleInstance` (second instance exits); generic host registers services as singletons; `app.manifest` declares PerMonitorV2 DPI awareness.
- `DockWindow`: `WindowStyle=None`, `AllowsTransparency=True`, `Background=Transparent`, `Topmost`, `ShowInTaskbar=False`; width = `MaxWindowWidth`, height = icon × max scale + padding; placed at `SystemParameters.WorkArea` bottom-center (DIPs).
- Items: horizontal `StackPanel`; each item's `Width/Height = IconSize × Scale` (so neighbors shift), bottom-aligned; translucent rounded plate behind the row.
- Mouse: `MouseMove` → `UpdateCursor(x)`; `MouseLeave` → `UpdateCursor(null)`; hook `CompositionTarget.Rendering` only while `Tick` returns true.
- Bounce: on `BounceRequested`, `TranslateTransform.Y` keyframes 0 → −24 → 0 → −12 → 0 over 0.7 s.
- WS_EX_TOOLWINDOW so the dock never shows in Alt+Tab.
